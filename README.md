# SurfChex VLC 24/7 Player

A Windows Python application that:

1. Opens the configured SurfChex camera page with Playwright.
2. Captures the authorized `.m3u8` HLS request generated by the page.
3. Starts VLC with that URL.
4. Monitors VLC continuously.
5. Reads the `e=<unix timestamp>` expiration value when present.
6. Refreshes the camera page before expiration.
7. Obtains a new signed `.m3u8`.
8. Restarts VLC.
9. Retries automatically after browser/network/VLC failures.

This does **not** modify or forge SurfChex signatures. It obtains a new URL through the normal camera page.

## Requirements

- Windows 10/11
- Python 3.11+
- VLC 64-bit
- Internet access

## Installation

Open PowerShell in this directory:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
```

## Configuration

Edit `config.yaml`.

The most important setting is:

```yaml
camera_page_url: "https://www.surfchex.com/ACTUAL-CAMERA-PAGE"
```

Use the actual SurfChex camera page that you normally open in Chrome.

You may leave the current signed URL in:

```yaml
initial_stream_url: "https://www.surfchex.com/hls/..."
```

It is only used for the first VLC launch. When it expires, Playwright gets a fresh URL.

If the page generates several HLS streams, narrow the capture filter:

```yaml
stream_url_regex: "video1_stream\\.m3u8"
```

## Run

```powershell
.\run.ps1
```

## Troubleshooting

Set:

```yaml
headless: false
```

Then run:

```powershell
.\run.ps1
```

A Chromium window will be visible. Watch the console/log for:

```text
Captured HLS request: https://...
```

If no `.m3u8` is captured:

1. Confirm `camera_page_url`.
2. Open that page manually in Chrome.
3. Press F12 -> Network -> Media.
4. Start the camera.
5. Confirm the request contains `.m3u8`.
6. Adjust `stream_url_contains` or `stream_url_regex`.

## Logs

Runtime logs are written to:

```text
logs/surfchex-vlc.log
```

## Long-running Windows use

For a true unattended 24/7 deployment, run the program using a Windows service manager or Task Scheduler with:

- Run whether user is logged on or not
- Restart on failure
- Start at system startup
- Appropriate network availability delay

For initial testing, run it interactively with:

```powershell
.\run.ps1
```

## Important note about the signed URL

A URL such as:

```text
https://www.surfchex.com/hls/...m3u8?st=...&e=...
```

is normally time-limited. Do not assume changing or removing `st`/`e` will make it permanent.

This project instead refreshes the authorized URL from the normal web page.
